# Watchlist

Projects that fit the scope of the [main list](README.md) but are announced, labelled in progress by their own maintainers, or missing parts of their documentation. They move into the main list once they are usable and documented. Nothing here is a judgement on quality — only on readiness.

Last checked: September 18, 2026.

## Agentic Commerce

- [magebitcom/magento2-agentic-commerce-module](https://github.com/magebitcom/magento2-agentic-commerce-module) - ACP integration for selling inside ChatGPT, targeting Hyvä, B2B and Adobe Commerce Cloud. Labelled in progress by its maintainers. MIT.
- [magebitcom/magento2-universal-commerce-module](https://github.com/magebitcom/magento2-universal-commerce-module) - Universal Commerce Protocol implementation. The readme marks it as coming soon: the checkout capability is done, order and identity linking are still open, and it includes a switch-off-by-default endpoint for the official UCP conformance suite. MIT.

## MCP Servers

- [magebitcom/magento2-mcp-module](https://github.com/magebitcom/magento2-mcp-module) - Admin. Server with per-tool role ACL, two-layer write gating, PII-redacted audit log and optional domain sub-modules, including [a catalog tool extension](https://github.com/magebitcom/magento2-mcp-catalog-tools). Labelled in progress by its maintainers. MIT.

## Moving to the main list

A project moves when its maintainers drop the in-progress or coming-soon label, or when it has a tagged release with installation docs. Open an issue if something here is ready.
